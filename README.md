# 📊 Inflation Forecasting & Price Shock Detection (India)

## 📌 Overview

This project focuses on forecasting inflation trends and detecting sudden price shocks using Indian economic indicators such as CPI (Consumer Price Index), WPI (Wholesale Price Index), and Repo Rate.

## 🎯 Objectives

- Predict future inflation using time series models
- Analyze relationship between CPI, WPI, and Repo Rate
- Detect abnormal spikes (price shocks) in inflation

## 📂 Dataset

- CPI (Consumer Price Index)
- WPI (Wholesale Price Index)
- Repo Rate (RBI Monetary Policy Data)

## ⚙️ Tech Stack

- Python
- NumPy
- Pandas
- Matplotlib
- Statsmodels

## 🔧 Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Time Series Analysis
5. Forecasting using ARIMA
6. Price Shock Detection

## 📈 Results

- Successfully visualized inflation trends
- Built a forecasting model for CPI
- Identified periods of sudden price shocks

## 🚀 Future Improvements

- Add SARIMA / LSTM models
- Include more features (Fuel prices, Exchange rate)
- Improve prediction accuracy
